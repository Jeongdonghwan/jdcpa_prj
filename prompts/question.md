# 질문형 글 (question)
검색어 "{{ combo.primary_keyword }}"로 찾아온 사람이 실제로 궁금해하는 질문 하나에 답하는 글을 씁니다.
- 업종: {{ vertical.name }}
{% if topic %}- 관련 주제: {{ topic.term }}
{% endif %}
## 쓰는 법
- 제목(h1)은 사람이 묻는 말투의 질문형으로 씁니다. 예: "○○이면 △△는 어떻게 되나요". 40자 이내, 검색어의 핵심 낱말을 넣습니다.
- intro 첫 문단 2~3문장에서 바로 답합니다. 상황에 따라 달라지면 무엇에 따라 달라지는지를 먼저 말합니다.
- body 는 소제목(h2) 3~4개: 달라지는 조건 → 준비하거나 확인할 것 → 자주 하는 오해 → 상담 전에 정리할 것 순서를 기본으로, 주제에 맞게 바꿉니다.
- 표(table: 항목 | 내용 | 달라지는 이유)나 번호 목록(ol)을 한 번 이상 씁니다.
- 이 검색어에만 해당하는 내용(이 상황·대상·조건에서 달라지는 점)을 씁니다. 업종 일반론은 짧게 끝냅니다.
- 문단은 2~3문장으로 짧게 끊습니다. "~하신가요?", "지금 바로", "믿을 수 있는" 같은 광고 말투를 쓰지 않습니다.

- 이 사이트는 광고 제휴처를 소개하는 정보 사이트입니다. 법률·보험·의료 자문처럼 쓰지 않고 일반 정보로 씁니다.
- "~하면 됩니다" 같은 단정 대신 "~한 경우가 있습니다", "~인지 확인이 필요합니다"처럼 씁니다.
